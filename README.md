# BarberFlow - Página de Espera & Agendamento para Barbearias 💈⚡

Página de espera (Landing Page / Coming Soon) moderna, responsiva e otimizada para captação de leads VIP do sistema **BarberFlow** — o sistema de agendamento online, gestão de barbeiros e notificações via WhatsApp para barbearias.

---

## 🚀 Recursos da Página

- 🎨 **Design Dark Premium**: Estética moderna estilo luxo com efeitos de glassmorphism, gradientes dourados e tipografia refinada.
- 📱 **100% Responsivo**: Layout otimizado para celulares, tablets e desktops.
- ⏱️ **Contador Regressivo (Countdown)**: Timer dinâmico em tempo real para o lançamento oficial.
- 📝 **Formulário Lista VIP**: Validação em tempo real, máscara para WhatsApp `(XX) XXXXX-XXXX` e salvamento de estado local.
- 📊 **Simulador Interativo de ROI / Economia**: Calculadora em tempo real mostrando faturamento recuperado com lembretes automáticos e horas economizadas no atendimento.
- ❓ **FAQ Interativo**: Seção sanfona (accordion) sanando dúvidas frequentes.
- 🍞 **Notificação Toast**: Feedback visual dinâmico ao enviar formulários.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Semântico e otimizado para SEO.
- **CSS3**: Vanilla CSS com variáveis CSS, Grid/Flexbox, backdrop-filter e animações.
- **JavaScript ES6+**: Manipulação de DOM, simulador de cálculos e persistência em `localStorage`.
- **Google Fonts**: *Outfit* e *Playfair Display*.
- **FontAwesome 6**: Ícones vetoriais modernos.
